MRS6240-P2512 跌倒监护便携版使用说明（Windows 10/11，64 位）

一、如何运行
1. 完整复制本文件所在的 MRS6240-Fall-Monitor 文件夹。
   必须保留 _internal 和其中的所有文件，不能只复制某一个 EXE。
2. 将文件夹放在可写位置，例如桌面或 D 盘普通文件夹。
   请勿直接在压缩包内或 Program Files 这类受限目录运行。
3. 双击 MRS6240Monitor.exe：简化监护界面。
   双击 MRS6240Engineering.exe：工程调试界面（点云、曲线、串口日志）。
   一次只用一个界面连接同一块雷达，避免串口或 SPI 被占用。
4. 接好已烧录匹配固件的雷达板，正常上电后点击界面中的“一键直连”。
   默认控制口 COM3、115200 波特率，SPI index=0。
   实际串口号可能变化，可在界面选择；无需为程序单独安装 Python。

二、另一台电脑首次使用
程序已经携带 Python、绘图库、pythonnet、HIF DLL 与 CH347 本地 DLL。
但 USB 驱动属于 Windows 系统组件，无法仅靠复制软件自动安装：
- 确认 CH347 SPI/USB 驱动和实际控制串口对应的驱动已经安装。
- drivers 内附项目原有的厂商驱动压缩包，仅在需要时解压，按板卡实际接口安装。
  不需要重复安装已经正常工作的驱动。
- HIF DLL 的目标框架是 .NET Framework 4.7.2，需兼容版本（建议 4.8 或 4.8.1）。
  新版 Windows 通常已具备；缺少时先从 Windows 功能或微软官方安装。
- 当前便携版仅在本机进行验证；另一台全新电脑仍需进行首次接板验证。

三、日志与故障定位
运行日志：本文件夹\logs\realtime_fall\
报警留证：本文件夹\logs\realtime_fall\evidence\
启动错误：本文件夹\logs\startup-error.json
界面异常：本文件夹\logs\last-error.json
程序文件夹可移动，日志与依赖不引用开发者电脑的 SDK 目录。
若日志目录无写入权限，启动错误会退回 Windows 临时目录 mrs6240-startup-error.json。

四、部署条件
跌倒判断由板端固件完成，EXE 用来显示、报警、配置和留证。
当前算法基线为顶部向下安装，高度 310 cm、俯角 90 度，XY ROI 各 -250..250 cm。
高度可通过界面修改并保存到板端；换安装方式或场地后需重新验证。
打包不会更改固件或跌倒算法阈值。

五、维护
build-manifest.json 记录构建时间、源提交、依赖版本及原始文件 SHA256。
厂商 DLL 和驱动是本地配套依赖，不随项目公开代码仓库发布；交付使用需遵循原厂许可。
EXE 未进行商业代码签名，Windows 可能提示“未知发布者”。
正常使用无需管理员权限；安装 USB 驱动可能需要管理员权限。

六、只读依赖自检（不打开雷达）
在 PowerShell 中进入本文件夹，执行：
  .\MRS6240Monitor.exe --self-test .\logs\self-test.json
查看 logs\self-test.json 中 passed 是否为 true。
该检查验证软件依赖，不代表雷达已连接，也不代表跌倒检测效果通过验收。
